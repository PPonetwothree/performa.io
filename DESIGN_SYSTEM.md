# Performa.io — Design System

## Brand
Performa.io
Tagline: **Performance, diagnosed.**

Tone:
Analytical, precise, executive, restrained.

## Layout
Desktop-first:
- max content width around 1440px
- persistent left navigation
- compact top header
- dense analytical canvas

Avoid excessive empty space.

## Color
Use a neutral enterprise palette.
Primary UI should be mostly neutral.
Use semantic status colors sparingly:
- positive
- warning
- critical
- informational

Do not use rainbow charts.
Do not use gradients as decoration.

## Typography
Use a modern sans-serif.
Strong hierarchy:
- page title
- section title
- KPI value
- supporting label
- metadata

## Components
Required:
- Sidebar
- Header
- FilterBar
- KPI Card
- Benchmark Card
- Status Badge
- Alert Card
- Chart Card
- Opportunity Card
- Data Table
- Empty State
- Loading State
- Error State
- Detail Drawer

## Charts
Charts must answer business questions.
Prefer:
- line charts
- horizontal bar charts
- scatter plots
- heatmaps
- Pareto charts

Avoid 3D charts and decorative gauges.

## Interaction
- hover tooltips
- clear selected states
- filter persistence while navigating
- clickable chart elements where useful
- no excessive animation

## Copy
Use business language:
"Performance gap"
"Margin pressure"
"Volume weakness"
"Priority opportunity"
"Recommended action"

Avoid:
"AI-powered"
"Revolutionary"
"Magic"
"Next-gen"

unless genuinely justified.

## Visual Standard
The application should resemble a high-end internal consulting/strategy analytics tool rather than a student project.
