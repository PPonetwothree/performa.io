- [ ] Demo data loads automatically.
- [ ] Navigation works.
- [ ] No blank dashboard.

## Data
- [ ] Valid CSV uploads.

- [ ] KPI totals reconcile with source data.

## Reports

- [ ] Print/export works if implemented.

## UX
- [ ] Loading states exist.

- [ ] API errors do not crash the application.
- [ ] Desktop layout is polished.
